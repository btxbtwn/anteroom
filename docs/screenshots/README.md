# README screenshots

These PNGs show Anteroom's React interface from this checkout, captured on October 23, 2026 at a 1600 × 1000 desktop viewport in the dark theme.

| File | View |
|---|---|
| `anteroom-workspace.png` | Sample inventory, listing chat, and the General form under Forms. |
| `anteroom-assistant.png` | Business assistant home and suggested questions. |
| `anteroom-providers.png` | Provider selection and ChatGPT setup, with every provider signed out. |

The capture used a separate temporary SQLite database with four fictional drafts and a hand-written sample chat. No AI generation, Vendoo connection, listing send, or publication ran. No personal inventory, product photos, credentials, or account details are included.

When refreshing the images:

1. Use an isolated data directory through `VENDOO_STUDIO_DATA_DIR`, separate ports, and a fresh browser profile. Keep real credentials and provider sessions out of the capture environment.
2. Add fictional drafts and sample chat text. Leave Chrome disconnected and providers signed out.
3. Use a 1600 × 1000 viewport and the dark theme. Collapse Suggestions, open the sample listing's Forms tab, then capture Assistant and Settings → Providers.
4. Wait for each view to finish loading. Inspect every image for clipped controls and private content before replacing it.
5. Keep the filenames and update the capture date above. Check the image links in the root README.
