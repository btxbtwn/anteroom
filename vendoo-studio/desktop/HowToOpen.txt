Anteroom

1. Unzip with Archive Utility or:
     ditto -xk Anteroom-macos.zip ~/Downloads/Anteroom
   (Prefer ditto over the unzip command — it keeps code signatures intact.)
2. Drag "Anteroom.app" into Applications.
3. Control-click the app and choose Open. Click Open again if macOS asks.
   You only do this the first time (the build is signed for local use, not Apple notarized).
4. In Settings, sign in with ChatGPT or paste a Xiaomi MiMo API key.
5. Click Connect Chrome. Anteroom opens Vendoo in your everyday Chrome.
6. Load the listing extension once:
   Copy the exact folder path from Settings → Connections in Anteroom.
   In Chrome open chrome://extensions, turn on Developer mode, and click Load unpacked.
   Press Control-Shift-G (⌘⇧G) to search for the folder, paste the path, click Go, then Open.
7. Sign in to Vendoo in that Chrome window, then create a listing.

Needs macOS 13+ and Google Chrome. Photos, listings, drafts, hidden fields,
settings, fill logs, and app logs stay on this Mac in:
  ~/Library/Application Support/Anteroom
API keys stay in macOS Keychain (same Mac, not inside that folder).
